# Catatan Perubahan

**Bahasa / Language:** [Bahasa Indonesia](CHANGELOG.id.md) | [English](CHANGELOG.md)

Perubahan penting dicatat di sini dengan bahasa sederhana. Catatan tetap berada pada bagian **Belum dirilis** sampai versi diberi tag.

## Belum dirilis

- Mengganti papan catur datar berbasis Unicode dengan scene perspektif 3D buatan sendiri.
- Menambahkan rotasi kamera melalui drag serta kontrol untuk mereset sudut pandang.
- Menjaga material buah putih dalam rentang putih/ivory dan buah hitam dalam rentang gelap yang konsisten.
- Memperluas GitHub Actions agar memeriksa build Android, Windows, Linux, macOS, kompilasi iOS, dan web.
- Menambahkan workflow rilis berbasis tag versi yang hanya menerbitkan artefak setelah pemeriksaan wajib berhasil.
- Menulis ulang dokumentasi proyek dengan bahasa Inggris dan Indonesia yang ramah pemula.
